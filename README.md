# Система сбора и анализа вакансий с HeadHunter API

## Описание
Проект представляет собой ETL-пайплайн для автоматизированного сбора данных о работодателях и вакансиях 
с публичного API hh.ru, их структурированного хранения в PostgreSQL. 
Система позволяет получать актуальную информацию с рынка труда для дальнейшего исследования и сравнения предложений от 
различных компаний.

Источник данных: публичный API hh.ru
Хранилище: реляционная БД PostgreSQL
Объём: данные от 10+ компаний-работодателей
Модульная архитектура с четким разделением ответственности.

# Установка

Клонируйте репозиторий:

``` git clone https://github.com/antondrevin/bank_project.git ```

**Установите зависимости, используя менеджер пакетов `poetry`:**
    
``` poetry install```

## Использование

Запустите программу, выберите действие 1 (запустить интерактивный интерфейс) или 0 (выход из программы).
Выберите действие от 1 до 0:
   1. Компании и количество вакансий      
   2. Показать все вакансии
   3. Узнать среднюю зарплату
   4. Вакансии с зарплатой выше средней
   5. Поиск вакансий по ключевому слову (введите ключевое слово)
   0. Выйти из программы

## Описание классов и функций:

1. конкретный класс HHAPI для работы с API сайта hh.ru (включает 2 метода)
2. класс DataTransformer преобразователь данных из формата API в формат БД (включает 4 метода)
3. Класс Database работает с базой данных PostgreSQL (включает 9 методов)
4. В модуле user_interface.py в корне проекта созданы методы взаимодействия пользователя с программой
5. Модуль main.py в корне проекта является основной точкой входа.
